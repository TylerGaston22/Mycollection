# styles/

All CSS for the app lives here. No CSS exists outside this directory.

| File | Purpose |
|------|---------|
| `index.css` | Compiled Tailwind CSS v4 output — utility classes, CSS custom property layer, and Tailwind internals. Imported once in `main.tsx` as the app's style entry point |
| `globals.css` | Hand-authored design tokens and base styles — CSS variables for colors, typography, radius, sidebar, and chart tokens in both light and dark mode. Also defines base typography rules for `h1`–`h4`, `p`, `label`, `button`, and `input` |
